Training Features

Beyond plain fit(), both Sequential and Regressor expose the training controls you normally reach for once a baseline works: reproducible seeding, early stopping, learning-rate schedules, gradient clipping, weight decay and layer freezing.

1. Seeded, Reproducible Training

Two sources of randomness exist: weight initialization (once, at construction) and epoch shuffling (every epoch). Fixing both makes a run bit-for-bit reproducible:

// Seed 42L fixes Glorot weight initialization
try (Sequential net = new Sequential(Optimizer.adam(0.01f), 42L,
        new Input(4), new Dense(32), new ReLU(), new Dense(3))) {

    net.setShuffleSeed(42L);   // same batch order every epoch, every run
    net.fit(trainX, trainY, 100, 32, testX, testY, true);
}
  • new Sequential(optimizer) and new Regressor(optimizer) default to seed 42.
  • The full constructors accept the seed explicitly: Sequential(optimizer, loss, labelSmoothing, initSeed, layers...).
  • Same seed + same data = identical training. Change only the seed to measure how stable your metrics really are.

2. EarlyStopping

EarlyStopping is a Keras-style callback passed to the fit overloads that accept it. Training stops when the monitored validation metric fails to improve for patience consecutive epochs. It doubles as the result holder afterwards.

EarlyStopping es = EarlyStopping.valLoss(10, true);   // patience 10, restore best

History h = net.fit(trainX, trainY, 500, 32, valX, valY, true, es);

System.out.println("stoppedEarly = " + es.stoppedEarly);
System.out.println("best epoch   = " + es.bestEpoch);     // 0-based
System.out.println("best score   = " + es.bestScore);
System.out.println("epochs run   = " + h.epochsRun());   // < 500 if stopped
Factory / field Meaning
valLoss(patience[, restore]) Monitor validation loss (lower is better). Supported by both Sequential and Regressor.
valAccuracy(patience, restore) Monitor validation accuracy (higher is better). Classifier models.
patience How many non-improving epochs to tolerate before stopping (must be ≥ 1).
restoreBestWeights Snapshot parameters at every new best epoch and write them back when training ends, so the model you keep is the best one, not the last one.
minDelta Improvement smaller than this counts as no improvement (default 0).

A validation set is required when early stopping is enabled - passing null validation data throws IllegalArgumentException. In practice you pass your test split as the monitored set in small projects, or hold out a dedicated third split for honest final evaluation.

// Typical pattern: generous epoch budget, let patience decide
EarlyStopping es = EarlyStopping.valLoss(15, true);
net.fit(trainX, trainY, 1000, 64, testX, testY, true, es);
// returns as soon as val_loss plateaus ~15 epochs

3. Learning-Rate Schedules

A LrSchedule expresses the learning rate as a fraction of the optimizer's configured rate. Before every epoch the model sets the effective rate to baseLr × fractionAt(epoch); Adam/momentum state is preserved across changes (no re-initialization).

net.setLrSchedule(LrSchedule.cosine(40, 0.01f)); // anneal to 1% over 40 epochs
net.fit(trainX, trainY, 40, 64, testX, testY, true);
Factory Profile
LrSchedule.cosine(totalEpochs, minFraction) Smooth cosine anneal from 1.0 down to minFraction, then flat. The usual default - large steps early, fine steps late.
LrSchedule.step(every, factor) Classic staircase: multiply by factor every every epochs (e.g. halve every 10).
LrSchedule.exponential(factor) factor^epoch per epoch, factor slightly below 1 (e.g. 0.98).
LrSchedule.constant() Identity hook - handy to toggle a schedule off without restructuring code.
Custom lambda epoch -> 1f / (1f + 0.05f * epoch) - any LrSchedule is a single method.

You can read back the current scaling with net.currentLrMultiplier() (classifier models) or inspect the optimizer's multiplier directly.

4. Gradient Clipping and Weight Decay

Both controls live on the optimizer and apply to every step of every model that uses it:

Optimizer opt = Optimizer.adam(0.005f);
opt.setGradClipNorm(5.0f);    // rescale grads when global norm exceeds 5
opt.setWeightDecay(1e-4f);    // decoupled (AdamW-style) decay

try (Regressor net = new Regressor(opt, 42L,
        new Input(6), new Dense(64), new ReLU(), new Dense(1))) {
    // ... fit() as usual
}
  • Gradient clipping (setGradClipNorm(maxNorm)): if the L2 norm across all gradient tensors exceeds maxNorm, all gradients are scaled down by maxNorm / norm. Use it whenever losses can spike - RNNs, high learning rates, noisy batches. A value like 1..10 rarely hurts; 0 disables.
  • Weight decay (setWeightDecay(decay)): adds decay × param to each gradient before the update rule - decoupled weight decay, exactly the AdamW formulation. It pulls weights toward zero each step, reducing overfitting on small datasets. Typical range 1e-5 .. 1e-3; 0 disables.

5. Layer Freezing (Transfer Learning)

setTrainable(layerIndex, trainable) freezes/unfreezes all parameters of one layer (index into the constructor list; the input layer at index 0 has no parameters). Frozen layers simply receive zero gradients - no recompilation, instant toggling:

try (Sequential net = Sequential.loadFrom(Path.of("cnn.bin"),
                                           Optimizer.adam(0.001f))) {

    // Freeze everything up to layer 4 (indices 1..4), fine-tune the head:
    for (int i = 1; i <= 4; i++) net.setTrainable(i, false);

    net.fit(newTrainX, newTrainY, 30, 64, testX, testY, true);

    net.unfreezeAll();                       // optional full fine-tune pass
    net.fit(newTrainX, newTrainY, 10, 64, testX, testY, true);
}

This enables the classic two-phase transfer recipe: load pretrained weights, freeze the feature extractor, train only the dense head, then optionally unfreeze and continue at a low learning rate.

6. Putting It Together

Optimizer opt = Optimizer.adam(0.01f);
opt.setWeightDecay(1e-4f);
opt.setGradClipNorm(5f);

try (Regressor net = new Regressor(opt, 42L,
        new Input(6),
        new Dense(64), new ReLU(),
        new Dense(32), new ReLU(),
        new Dense(1))) {

    net.setShuffleSeed(42L);
    net.setLrSchedule(LrSchedule.cosine(300, 0.01f));

    EarlyStopping es = EarlyStopping.valLoss(20, true);
    Regressor.RegressionHistory h =
            net.fit(trainX, trainY, 300, 32, testX, testY, true, es);

    System.out.printf("ran %d/%d epochs, best val MSE %.5f at epoch %d%n",
            h.epochsRun(), 300, es.bestScore, es.bestEpoch + 1);
}
