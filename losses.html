Loss Functions in TensorFlow C API Java

Loss functions measure the difference between predicted and actual values. The tensorflow-capi-java library supports multiple loss strategies through the Sequential.Loss enum.

1. Supported Loss Strategies

1.1. SPARSE_CROSS_ENTROPY (Default)

// Default loss for multi-class classification with integer labels
Sequential net = new Sequential(new Adam(0.001f),
        layers,
        Loss.SPARSE_CROSS_ENTROPY);  // or just new Sequential(optimizer, layers)

Formula: L = -\log(p_{y}), where p_{y} is the predicted probability for the true class

Used with: Integer labels (0, 1, ..., K-1), softmax output layer

Label Smoothing (optional):

// With label smoothing (eps = 0.1 adds 10% uniform noise)
Sequential net = new Sequential(new Adam(0.001f), 
        Loss.SPARSE_CROSS_ENTROPY, 0.1f, layers);

Effect: Prevents model from becoming overconfident, often improves generalization

1.2. SOFTMAX_MSE

// Mean squared error between softmax probabilities and one-hot targets
Sequential net = new Sequential(new Adam(0.001f),
        Loss.SOFTMAX_MSE, layers);

Formula: L = \frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{K}(p_{ij} - y_{ij}^{one-hot})^2

Where p_{ij} is the softmax probability for class j sample i, and y_{ij}^{one-hot} is the one-hot target.

Properties:

  • Square loss on probability outputs
  • Differentiable almost everywhere
  • Can be seen as a "distillation-style" loss

1.3. SIGMOID_CROSS_ENTROPY

// Binary cross-entropy with sigmoid activation per class
Sequential net = new Sequential(new Adam(0.001f),
        Loss.SIGMOID_CROSS_ENTROPY, layers);

Formula: L = -\frac{1}{N}\sum_{n=1}^{N}\sum_{k=1}^{K}[y_{nk}\log(\sigma(z_{nk})) + (1-y_{nk})\log(1-\sigma(z_{nk}))

Where \sigma is sigmoid, z are logits, and y are binary targets (0 or 1).

Used for: Multi-label classification or when each class is independent

2. Loss Function Comparison

Loss Function Type Output Activation Label Format Best Use Case
SPARSE_CROSS_ENTROPY Classification Softmax Integer (0..K-1) Standard multi-class classification
SOFTMAX_MSE Classification (MSE on probs) Softmax Integer (0..K-1) Alternative to cross-entropy
SIGMOID_CROSS_ENTROPY Classification (multi-label) Sigmoid Binary (0/1) per class Multi-label or independent binary problems

3. Implementation Details

3.1. Building the Loss Operation

// From Sequential.java - buildLossOp method
private long buildLossOp(GraphBuilder gb, Flow f, Loss loss, float labelSmoothing) {
    long yPh = gb.placeholder("y", NativeTF.DT_INT32, Shape.of(-1));
    long oneHot = graph.op("OneHot", gb.unique("onehot"))
            .attrType("T", NativeTF.DT_FLOAT)
            .attrType("TI", NativeTF.DT_INT32)
            .attrInt("axis", -1)
            .input(yPh)
            .input(gb.constI32Vec("num_classes", numClasses))
            .input(gb.constF32("on_value", 1.0f))
            .input(gb.constF32("off_value", 0.0f))
            .build();
    oneHot = gb.unary("StopGradient", "onehot_sg", oneHot);
    
    // Apply label smoothing if requested
    if (labelSmoothing > 0f && labelSmoothing < 1f) {
        oneHot = gb.binary("Mul", "ls_mul", oneHot, gb.constF32(1f - labelSmoothing));
        oneHot = gb.binary("Add", "ls_add", oneHot,
                gb.constF32(labelSmoothing / numClasses));
    }
    
    long softmax = gb.unary("Softmax", "softmax", f.op);
    return loss.build(softmax, oneHot, numClasses);
}

3.2. Each Loss Strategy's Graph Construction

SPARSE_CROSS_ENTROPY

// LossOp.build() for SPARSE_CROSS_ENTROPY:
long softmax = (float[]) args[0];
float[] oneHot = (float[]) args[1];
int numClasses = (int) args[2];

// LogSoftmax (numerically stable)
long logSoftmax = gb.unary("LogSoftmax", "log_softmax", softmax);

// Element-wise multiplication with one-hot
long mul = gb.binary("Mul", "cel_mul", logSoftmax, oneHot);

// Sum over classes (axis=-1 reduced to scalar per sample)
long sum = gb.binary("Sum", "cel_sum", mul, gb.constI32Vec("ce_axis", 1));

// Negate
long neg = gb.unary("Neg", "cel_neg", sum);

// Mean over batch
long lossOp = graph.op("Mean", "loss")     // simplified - actual uses Mean with Tidx
        .attrType("T", NativeTF.DT_FLOAT)
        .attrType("Tidx", NativeTF.DT_INT32)
        .input(neg)
        .input(gb.constI32Vec("loss_axis", 0))
        .build();

SOFTMAX_MSE

// LossOp.build() for SOFTMAX_MSE:
long softmax = (float[]) args[0];
float[] oneHot = (float[]) args[1];

// Compute (p - y_onehot)^2 element-wise
long diff = gb.binary("Sub", "mse_diff", softmax, oneHot);
long square = gb.unary("Square", "mse_square", diff);  // Square via Mul(diff, diff) or custom
long mean = graph.op("Mean", "mse_mean")
        .attrType("T", NativeTF.DT_FLOAT)
        .input(square)
        .build();

SIGMOID_CROSS_ENTROPY

// LossOp.build() for SIGMOID_CROSS_ENTROPY:
long softmax = (float[]) args[0];
float[] oneHot = (float[]) args[1];

// Apply sigmoid to logits
long sigmoid = gb.unary("Sigmoid", "sigmoid", softmax);

// Clip to avoid log(0)
long eps = gb.constF32(1e-7f);
long clipped = gb.binary("Add", "clip_eps", sigmoid, eps);  // simplified - actual uses max/min

// Binary cross-entropy: -[y*log(p) + (1-y)*log(1-p)]
long logPos = gb.unary("Log", "bce_log_pos", clipped);
long logNeg = gb.unary("Log", "bce_log_neg", gb.binary("Sub", "one_minus", clipped, eps));
long mulPos = gb.binary("Mul", "bce_mul_pos", oneHot, logPos);
long mulNeg = gb.binary("Mul", "bce_mul_neg", gb.binary("Sub", "one_minus_y", oneHot, eps), logNeg);
long sum = gb.binary("Add", "bce_sum", mulPos, mulNeg);
long mean = graph.op("Mean", "bce_mean")
        .attrType("T", NativeTF.DT_FLOAT)
        .input(sum)
        .build();

4. Choosing the Right Loss

  • Standard multi-class classification: Use SPARSE_CROSS_ENTROPY (default)
  • Label smoothing regularization: Add labelSmoothing=0.1 to SPARSE_CROSS_ENTROPY
  • Alternative divergence measure: Try SOFTMAX_MSE
  • Multi-label / independent binary problems: Use SIGMOID_CROSS_ENTROPY

5. Checkpoint Compatibility

The checkpoint format version was bumped to 2 to support loss type persistence:

  • v1 checkpoints: Loaded silently, loss defaults to SPARSE_CROSS_ENTROPY
  • v2 checkpoints: Save and restore the loss type and label smoothing value
// Saving a checkpoint with custom loss
net.saveTo(Path.of("my_model.bin"));

// Loading (automatically handles v1 and v2)
Sequential loaded = Sequential.loadFrom(Path.of("my_model.bin"), optimizer);
