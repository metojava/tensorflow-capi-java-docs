Activation Functions in TensorFlow C API Java

Activation functions introduce non-linearity into neural networks, enabling them to learn complex patterns. The tensorflow-capi-java library provides several built-in activation layers.

1. Built-In Activation Layers

1.1. ReLU (Rectified Linear Unit)

// Usage in Sequential
try (Sequential net = new Sequential(0.01f,
        new Input4D(28, 28, 1),
        new Conv2D(16, 3, 3, 1, 1, Padding.SAME), new ReLU(),
        new MaxPool2D(2, 2, 2, 2, Padding.VALID)) {
    // ReLU(x) = max(0, x)
    // y = x if x > 0, else y = 0
}

Formula: f(x) = max(0, x)

Properties:

  • Computational efficiency: simple threshold operation
  • Mitigates vanishing gradient problem compared to sigmoid/tanh
  • However, can suffer from "dying ReLU" problem (neurons output 0 always)

1.2. Sigmoid

// Usage
new Sigmoid()

Formula: f(x) = 1 / (1 + e^{-x})

Range: (0, 1)

Properties:

  • S-shaped curve, outputs probability-like values
  • Used in binary classification output layer
  • Suffers from vanishing gradient for extreme values
  • Not recommended for hidden layers in modern CNNs

1.3. Tanh (Hyperbolic Tangent)

// Usage
new Tanh()

Formula: f(x) = (e^{x} - e^{-x}) / (e^{x} + e^{-x}) = \frac{e^{2x} - 1}{e^{2x} + 1}

Range: (-1, 1)

Properties:

  • Zero-centered (mean of outputs is near 0)
  • Better than sigmoid for hidden layers
  • Still suffers from vanishing gradient for extreme values

1.4. Softmax

// Usage (typically in output layer for multi-class classification)
new Softmax()

Formula: f(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}

Properties:

  • Converts logits to probabilities that sum to 1
  • Used in multi-class classification output layer
  • Output can be fed to Metrics.argmax() to get predicted class

1.5. ELU (Exponential Linear Unit)

// Usage
new ELU()

Formula: f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha(e^{x} - 1) & \text{if } x \le 0 \end{cases}

Typically \alpha = 1

Properties:

  • Negative values are mapped to a negative saturating region
  • Can accelerate convergence versus ReLU
  • Smooth at x=0

1.6. ReLU Variants

1.6.1. LeakyReLU

// Usage: LeakyReLU(negativeSlope)
new LeakyReLU(0.01f)

Formula: f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha x & \text{if } x \le 0 \end{cases}

Where \alpha is a small constant (e.g., 0.01)

Purpose: Addresses dying ReLU by allowing small gradient when x ≤ 0

1.6.2. GELU (Gaussian Error Linear Unit)

// Usage
new GELU()

Formula: f(x) = x \cdot \Phi(x), where \Phi is the CDF of the standard normal distribution

Popularity: Became dominant in NLP (BERT, GPT) and vision transformers

1.6.3. SELU (Scaled Exponential Linear Unit)

// Usage
new SELU()

Formula: f(x) = \lambda \begin{cases} x & \text{if } x > 0 \\ \alpha(e^{x} - 1) & \text{if } x \le 0 \end{cases}

Where \lambda \approx 1.0507 and \alpha \approx 1.6733

Property: Enables self-normalizing neural networks (SNN)

1.6.4. SiLU (Swish) or GELU variants

// Usage
new SiLU()

Formula: f(x) = x \cdot \sigma(x), where \sigma is sigmoid

1.7. Softplus

// Usage
new Softplus()

Formula: f(x) = \ln(1 + e^{x})

Properties:

  • Smooth approximation to ReLU
  • Always positive, derivative is sigmoid
  • Smooth everywhere (no kink at x=0)

1.8. Softmax vs. Sigmoid vs. Tanh Comparison

Function Range Best Use Case
Sigmoid (0, 1) Binary classification output
Tanh (-1, 1) Hidden layers (zero-centered)
Softmax Probability distribution (sums to 1) Multi-class classification output

2. Choosing the Right Activation

  • Hidden layers: ReLU (most common), LeakyReLU (if dying ReLU issue), SELU (self-normalizing)
  • Output (multi-class): Softmax
  • Output (binary): Sigmoid
  • Output (regression): Linear (no activation) or Tanh

3. Implementation in tensorflow-capi-java

All the above activation functions are available as subclasses of Layer in the com.example.tfcapi package. They can be used in a Sequential model:

// Example: CNN with mixed activations
try (Sequential net = new Sequential(new Adam(0.001f),
        new Input4D(28, 28, 1),
        new Conv2D(32, 3, 3, 1, 1, Padding.SAME), new ReLU(),
        new Conv2D(64, 3, 3, 1, 1, Padding.SAME), new LeakyReLU(0.1f),
        new MaxPool2D(2, 2, 2, 2, Padding.VALID),
        new Flatten(),
        new Dense(128), new SELU(),  // Self-normalizing
        new Dense(10), new Softmax()) {  // Output layer
    // Train...
}

4. Gradient Flow Considerations

The choice of activation affects backpropagation (gradient flow):

  • ReLU: Gradient is 1 for x > 0, 0 for x ≤ 0. Enables training of very deep networks.
  • Sigmoid/Tanh: Gradients saturate for extreme values, making deep training difficult (vanishing gradient problem).
  • ReLU variants (LeakyReLU, ELU, SELU): Provide non-zero gradients for negative values, enabling better training dynamics.

5. Summary

  • ReLU is the default choice for hidden layers in modern CNNs
  • Softmax for multi-class output, Sigmoid for binary
  • Experiment with LeakyReLU/ELU/SELU if experiencing vanishing gradients
  • All activations are available in tensorflow-capi-java via Layer subclasses
