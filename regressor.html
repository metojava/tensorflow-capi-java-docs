Regressor - Predicting Continuous Targets

Regressor is the Keras-style regression twin of Sequential. Architecturally it uses the same composable layer set, but the label placeholder is a float tensor, the training objective is mean squared error (MSE), and predict() returns raw network outputs - no softmax.

1. Minimal Example

try (Regressor net = new Regressor(Optimizer.adam(0.01f), 42L,
        new Input(4),
        new Dense(24), new ReLU(),
        new Dense(1))) {

    net.setShuffleSeed(42L);                       // reproducible epoch shuffling
    Regressor.RegressionHistory h =
            net.fit(trainX, trainY, 200, 32, testX, testY, true);

    float[] preds = net.predict(testX);            // one float per output unit
    double mse = net.mse(testX, testY);
    net.saveTo(Path.of("model.bin"));
}

Targets (trainY/testY) are flat float arrays: one value per row for scalar regression, or rows × outputs values laid out row-major for multi-output regression. This is what makes Regressor perfect for targets that are not class ids - prices, temperatures, pixel intensities (see the autoencoder project, which regresses whole images).

2. Construction Rules

Rule Detail
First layer Must be Input, Input3D or Input4D
Last layer Must be Dense(units) - units becomes the number of regression outputs. Use Dense(1) for scalar targets.
No activation on the output Predictions are unbounded linear outputs. Do not put ReLU/Sigmoid after the final Dense unless your targets are genuinely bounded.
Seeded constructor new Regressor(optimizer, seed, layers...) fixes Glorot weight initialization; combine with setShuffleSeed() for fully reproducible runs.
AutoCloseable Always wrap in try-with-resources to release the native graph and optimizer state.

3. Loss and Training Loop

The training op is loss = mean((pred - y)2). Gradients come from TensorFlow's native TF_AddGradients, exactly as in Sequential. The full-loop signature:

// Without early stopping
RegressionHistory fit(float[] trainX, float[] trainY,
                      int epochs, int batchSize,
                      float[] valX, float[] valY, boolean verbose);

// With EarlyStopping (monitors validation loss)
RegressionHistory fit(float[] trainX, float[] trainY,
                      int epochs, int batchSize,
                      float[] valX, float[] valY, boolean verbose,
                      EarlyStopping es);

The returned RegressionHistory records per-epoch curves:

h.trainLoss[i]      // mean MSE on the training set for epoch i
h.valLoss[i]        // mean MSE on the validation set (NaN if no val data)
h.epochsRun()       // epochs actually executed (< requested if early stop fired)
h.finalTrainLoss();
h.finalValLoss();

4. Prediction and Evaluation

float[] preds = net.predict(batchX);   // rows * outputs raw floats
float mse     = net.mse(x, y);         // convenience: MSE over a whole set

// Derived metrics you typically compute yourself:
double rmse = Math.sqrt(mse);
// MAE and R^2 from preds vs targets:
double mae = 0, ssRes = 0, ssTot = 0;
double yBar = mean(trainY);
for (int i = 0; i < testN; i++) {
    double e = preds[i] - testY[i];
    mae += Math.abs(e);
    ssRes += e * e;
    ssTot += (testY[i] - yBar) * (testY[i] - yBar);
}
mae /= testN;
double r2 = 1 - ssRes / ssTot;
  • MSE / RMSE: quadratic loss; RMSE is in target units (dollars, degrees...).
  • MAE: robust summary - less sensitive to outlier errors than RMSE.
  • R²: fraction of target variance explained; 1.0 is perfect, 0.0 equals predicting the mean.

5. Regression-Specific Tips

  • Standardize features with Datasets.fitStandardizer fitted on the training split only - unstandardized wide-range inputs make gradient descent take wildly mismatched steps per weight.
  • Consider standardizing the target too. If prices span 50k..600k, training on z-scored targets converges much faster; multiply predictions by std + mean afterwards.
  • Prefer Adam at 0.01..0.001 and let EarlyStopping find the stopping point instead of hand-tuning epochs.
  • Beware heteroscedastic noise: MSE fits the mean. If outliers dominate, try predicting the log of the target.

6. Checkpoints

// Save architecture spec + weights ("TFRG" format, version 1)
net.saveTo(Path.of("regressor.bin"));

// Restore; pass an optimizer (state is fresh, weights come from the file)
Regressor loaded = Regressor.loadFrom(Path.of("regressor.bin"),
                                      Optimizer.adam(0.01f));

All model-level features work identically on Regressor: LR schedules (setLrSchedule), gradient clipping and weight decay (on the optimizer), layer freezing (setTrainable) - see Training Features.

7. Summary

  • Regressor = Sequential with float labels + MSE loss + linear outputs
  • Last layer must be Dense(outputs); start with Input/Input3D/Input4D
  • Targets are flat floats: rows * outputs
  • Evaluate with mse(), then derive RMSE/MAE/R²
