Machine Learning Fundamentals

1. What is Machine Learning?

Machine Learning (ML) is a branch of artificial intelligence that enables systems to learn from data and improve their performance without being explicitly programmed. The core idea is to discover patterns in data that can be used to make predictions or decisions.

2. Key Concepts

2.1. Training vs. Testing

  • Training set: Data used to train the model (adjust internal parameters)
  • Test set: Unseen data used to evaluate model performance
  • Typical split: 80% training, 20% testing

2.2. Features and Labels

  • Features (X): Input variables or attributes (e.g., pixel values of an image)
  • Labels (y): Target output or ground truth (e.g., digit class 0-9)

2.3. Model

A mathematical function that maps inputs to outputs: y = f(x; θ), where θ are learned parameters (weights and biases).

3. The ML Pipeline

  1. Collect and preprocess data
  2. Split into training and test sets
  3. Design model architecture (layers, activation functions)
  4. Choose loss function (how to measure error)
  5. Choose optimizer (how to update weights)
  6. Train the model (forward pass, loss computation, backward pass)
  7. Evaluate on test set
  8. Deploy or use for predictions

5. Key Takeaways

  • ML is about learning patterns from data, not explicit programming
  • The quality and quantity of data significantly impact model performance
  • Proper preprocessing (normalization, augmentation) is crucial
  • The choice of architecture, loss function, and optimizer affects training dynamics
  • Always evaluate on unseen test data, not training data
