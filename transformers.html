Transformers

A Transformer replaces recurrence with attention: every position of a sequence compares itself against every other position in a single parallel step, so long-range dependencies become one hop instead of a chain of hidden-state handoffs. This page explains the architecture piece by piece, maps each component to what exists in tensorflow-capi-java today, and shows what you can - and cannot - build right now.

1. Anatomy of a Transformer Block

input [B,T,D]
   |
   |--> Multi-Head Self-Attention      every position queries all others
   |        Q,K,V = x·Wq, x·Wk, x·Wv
   |        scores = QKᴹ/√d_head     [B, heads, T, T]
   |        weights = softmax(scores)
   |        heads = weights·V          concat --> WO
   |--> Add & LayerNorm                residual + per-position normalization
   |--> Feed-Forward                   Dense(dff) -> ReLU -> Dense(D)
   |--> Add & LayerNorm
   |
output [B,T,D]      ...repeat N times, then task-specific head

The decoder half adds two more pieces: masked self-attention (positions may not peek at the future) and cross-attention, where queries come from the decoder but keys/values come from the encoder output. Position information, which attention itself is blind to, is injected by positional encodings added to the input.

2. Component Map: Paper vs This Library

Component Status How
Scaled dot-product self-attention
(single head)		 Available SelfAttention() layer - trainable Q/K/V projections, residual, shape preserved. Verified by SelfTest.
Feed-forward sub-layer Available DenseND(n) - position-wise Dense on any rank, weights shared across positions. Verified by SelfTest.
Residual connections Built in SelfAttention already adds its input back; Residual layer exists for arbitrary blocks.
LayerNorm Missing BatchNorm1D normalizes over the BATCH axis, not the feature axis - not the same thing. Would need a small new layer.
Multi-head attention Available MultiHeadAttention(heads[, causal]) - per-head column slices, rank-3 throughout.
Positional encoding Available PositionalEncoding() - parameter-free sinusoids baked into a constant tensor.
Cross-attention
(encoder→decoder)		 Available* CrossAttention(queryLen) - queries from the leading segment attend to the trailing segment of ONE flow (*segment form; two-model cross-attention still needs GraphBuilder assembly).
Masking / causal attention Available MultiHeadAttention(heads, true) - upper-triangular -1e9 mask before softmax.

3. What You Can Build Today

3.1 Attention-augmented recurrent nets (works now)

The sweet spot with current pieces: self-attention blocks FIRST (pairwise mixing on the intact sequence), then an LSTM for order-aware summarization, then the head:

try (Sequential net = new Sequential(Optimizer.adam(0.01f), 42L,
        new Input3D(T, V),
        new SelfAttention(),
        new SelfAttention(),
        new LSTM(48),
        new Dense(classes))) { ... }

3.2 Pure attention classifier (works now, verified)

For tasks that are ORDER-FREE, drop recurrence entirely. The attention-vs-lstm project trains both stacks on needle-in-haystack retrieval ("does the probe digit appear among these?"): both reach 100% test accuracy, but the attention stack converges ~2.6× faster (early stop at epoch 52 vs 135).

new Input3D(T, V),
new SelfAttention(),
new SelfAttention(),
new Flatten(),
new Dropout(0.2f),
new Dense(24), new ReLU(),
new Dense(2)

3.3 A hand-wired encoder block (advanced)

Everything a Transformer block needs is expressible with public ops - BatchMatMulV2, Softmax, Transpose, Mean-based normalization, AddV2. The GraphBuilder page's linear-regression demo shows the pattern: placeholders → ops → addGradients → optimizer loop. A minimal LayerNorm from primitives:

// per-position feature normalization (LayerNorm-style):
long mean = reduceMean(x, /*axis*/ 2);            // [B,T,1]
long centered = gb.binary("Sub", ..., x, mean);
long var = reduceMean(gb.binary("Mul", ..., centered, centered), 2);
long norm = gb.binary("Mul", ..., centered,
                      gb.unary("Rsqrt", ..., gb.binary("AddV2", ..., var, eps)));
long out = gb.binary("AddV2", ..., gb.binary("Mul", ..., gammaBcast, norm), betaBcast);

Note the reduction-axis gotcha from the GraphBuilder page: axes constants must CARRY the axis value.

4. Roadmap to Full Transformers - COMPLETE

Every piece of the paper architecture now exists as a Java-only layer (all covered by SelfTest - 24 passed, 0 failed):

  • Shipped: PositionalEncoding, SelfAttention, MultiHeadAttention (+ causal masking), LayerNorm1D, DenseND, CrossAttention (segment form).

A full Transformer-style encoder block is literally a one-liner stack today:

new Input3D(T, D),
new PositionalEncoding(),
new MultiHeadAttention(4),
new LayerNorm1D(),
new DenseND(64), new ReLU(),   // feed-forward sub-layer
new DenseND(D),
new LayerNorm1D(),
... repeat blocks ...

The one remaining frontier is TRUE two-model cross-attention (a decoder attending to a separately-encoded input) - the segment-based CrossAttention covers the common matching/retrieval cases, while full seq2seq generation still needs GraphBuilder assembly or an interface extension.

5. Summary

  • Attention replaces sequential memory with pairwise lookup - one hop to anywhere.
  • All core Transformer components are implemented and tested: positional encoding, multi-head attention with causal masking, layer normalization, position-wise feed-forward, and cross-segment attention.
  • Verified end-to-end: SelfTest 24/24 including classification through every new layer; retrieval via cross-attention at >90% accuracy.
  • Everything above is pure Java graph wiring - zero native changes.

Further reading: Attention Is All You Need (Vaswani et al., 2017) - the paper that defined the architecture above.
