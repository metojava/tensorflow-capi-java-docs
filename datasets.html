Datasets - Loading, Splitting and Scaling

Datasets is a utility class of static helpers for the unglamorous half of machine learning: loading CSVs, splitting rows, standardizing features and encoding labels. All methods run once per program (not per batch) and are deliberately simple.

1. The Standard Pipeline

// 1. Read a CSV from the classpath ("/data/..") or file system
List<String[]> rows = Datasets.readCsv("/data/housing.csv", ",");

// 2. Drop the header row and select feature / label columns
float[] X = Datasets.toFloatFeatures(rows.subList(1, rows.size()), 0, 1, 2);
float[] Y = Datasets.toFloatColumn(rows.subList(1, rows.size()), 3);

// 3. Deterministic shuffled train/test split
int[][] split = Datasets.trainTestSplit(numRows, 0.3, 42L);
int[] trainIdx = split[0], testIdx = split[1];

// 4. Gather rows into flat matrices
float[] trainX = Datasets.gatherRows(X, trainIdx, numFeatures);
float[] testX  = Datasets.gatherRows(X, testIdx, numFeatures);

// 5. Standardize with TRAINING statistics only
float[][] norm = Datasets.fitStandardizer(trainX, numFeatures);
Datasets.applyStandardizer(trainX, norm[0], norm[1]);
Datasets.applyStandardizer(testX,  norm[0], norm[1]);

// 6. Train...

2. Method Reference

Method Purpose
readCsv(location, delimiter) Reads delimited text from a classpath resource (leading /) or file path. Skips blank lines, trims cells, returns every row including any header.
toFloatFeatures(rows, cols...) Selected columns as one flat row-major float matrix (rows × cols.length).
toFloatColumn(rows, col) One numeric column as float[] (regression targets).
toIntColumn(rows, col) One integer column as int[] (class ids for Sequential.fit).
trainTestSplit(n, testFraction, seed) Seeded Fisher-Yates shuffle of indices 0..n-1, split round-robin into {trainIndices, testIndices}. Same arguments always produce the same split.
fitStandardizer(flat, features) Per-feature mean and std of a flat row-major matrix; returns {mean[], std[]}. Fit on TRAIN data only.
applyStandardizer(flat, mean, std) In-place z-score: (x - mean) / (std + 1e-8).
gatherRows(flat, indices, rowElems) Copies selected rows of a flat matrix into a new array (apply the split indices).
gatherValues(values, indices) Same for 1-D label arrays: out[i] = values[idx[i]].
oneHot(label, numClasses) Unit-vector encoding: oneHot(2, 4) -> [0,0,1,0].

3. Why Seeded Splits Matter

int[][] s1 = Datasets.trainTestSplit(1000, 0.3, 42L);
int[][] s2 = Datasets.trainTestSplit(1000, 0.3, 42L);
// s1 equals s2 exactly - reproducible experiments

A fixed seed means a colleague re-running your program sees identical metrics. Changing only the seed gives you a fresh, equally valid split - useful for measuring how much of your accuracy is luck:

  • Run training with seeds 42, 43, 44... and average the metrics; if the spread is large, your model (or dataset) is unstable.
  • Never compare two models on different splits.

4. Avoiding Leakage with fitStandardizer

The golden rule: statistics that describe the data must come from the training split only, then be applied unchanged to the test split.

// CORRECT: fit on train, apply to both
float[][] norm = Datasets.fitStandardizer(trainX, FEATURES);
Datasets.applyStandardizer(trainX, norm[0], norm[1]);
Datasets.applyStandardizer(testX,  norm[0], norm[1]);

// WRONG: fitting on all rows lets test-set means/stds
// influence training - small but real optimistic bias
float[][] leaky = Datasets.fitStandardizer(allX, FEATURES);

5. Working Without Files

Several showcase projects generate synthetic datasets in code with a fixed seed (house prices, autoencoder patterns). The same Datasets helpers apply afterwards - generation replaces only step 1-2 of the pipeline. See house-price-regressor for a complete end-to-end example.

6. Summary

  • readCsv handles classpath resources and files with any delimiter
  • trainTestSplit(n, frac, seed) = deterministic shuffled index split
  • gatherRows/gatherValues materialize the split
  • fitStandardizer on train, applyStandardizer to both splits - no leakage
  • Everything feeds directly into Regressor / Sequential.fit
