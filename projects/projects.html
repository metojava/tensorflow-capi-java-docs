How to Run Any Project

cd C:\Users\dell\Desktop\tfcapi-docs\projects\<project-name>
run.cmd

Each run.cmd sets TF_CAPI_NATIVE_DIR to the TensorFlow native DLL folder, then runs mvn compile exec:java. Requirements: JDK 17+, Maven on PATH.

Shared Concepts

  • Classification models use Sequential; the regression and autoencoder projects use Regressor. Both train via fit(); gradients come from TensorFlow's native TF_AddGradients.
  • Datasets are either bundled in src/main/resources/data/, generated deterministically in code, or loaded from the local MNIST/Fashion-MNIST folders.
  • Evaluation always ends with a metrics report and (where useful) a confusion matrix via Metrics.printReport.
