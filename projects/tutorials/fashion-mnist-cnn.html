Tutorial 6 - Fashion-MNIST CNN with DepthwiseConv2D

Project Overview

Classify 28×28 grayscale images of clothing into ten classes (T-shirt, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot). Fashion-MNIST is a drop-in replacement for digit MNIST with the exact same file format and split sizes - but it is genuinely harder: a plain MLP plateaus around 88%, while this CNN reaches ~91-92% after 8 epochs. The architecture also showcases DepthwiseConv2D, the cheap half of a separable convolution.

The Dataset

The four IDX files (train-images-idx3-ubyte.gz, train-labels-idx1-ubyte.gz, plus the t10k- test pair) are read directly from disk - no extraction needed. The project takes the data directory as its first argument:

String dataDir = "C:\\Users\\dell\\Desktop\\data\\fashion";   // default
IdxDataset.Images trI = IdxDataset.loadImages(
        Path.of(dataDir, "train-images-idx3-ubyte.gz").toString());
float[] trainX = IdxDataset.normalize(trI.pixels());   // uint8 -> [0,1]
  • 60,000 train / 10,000 test images, pixel values scaled from 0..255 to 0..1.
  • Labels 0..9 map to Metrics.FASHION_CLASS_NAMES, which ships with the library so every project prints identical class names.
  • No shuffling worries - fit() reshuffles mini-batches internally every epoch.

Separable Convolutions: the Parameter Math

A regular Conv2D(32,3,3) sliding over 32 input channels learns one 3×3×32 kernel per output channel:

LayerKernel shapeWeights
Conv2D(32) on 32 channels32 × (3×3×32)9,216
DepthwiseConv2D(32) on 32 channels32 × (3×3×1)288

A depthwise conv applies an independent 3×3 filter to each channel instead of mixing all channels together - roughly 32× fewer parameters here. It cannot learn cross-channel combinations by itself, which is why it works best stacked after a normal Conv2D that has already created meaningful channels (this pattern is the "depthwise separable" idea behind MobileNet). In our network it acts as a cheap spatial refinement pass before pooling.

Model Architecture

Input4D(28, 28, 1)
Conv2D(32, 3, 3, s1, s1, SAME)   ReLU     28x28x32  - learn wide features
DepthwiseConv2D(32,3,3,s1,s1,SAME) ReLU   28x28x32  - refine each channel cheaply
MaxPool2D(2, 2, 2, 2, VALID)              14x14x32  - downsample
Flatten()                                  6272
Dense(128)  ReLU  Dropout(0.25)
Dense(10)                                  one score per class

Spatial size bookkeeping with stride 1 and SAME padding the feature maps stay 28×28 through both convolutions; VALID 2×2 pooling then halves them to 14×14. As always, the last layer must be Dense(numClasses) - Sequential reads the class count from it.

Training Code Walkthrough

try (Sequential net = new Sequential(Optimizer.adam(0.001f),
        new Input4D(28, 28, 1),
        new Conv2D(32, 3, 3, 1, 1, Padding.SAME), new ReLU(),
        new DepthwiseConv2D(32, 3, 3, 1, 1, Padding.SAME), new ReLU(),
        new MaxPool2D(2, 2, 2, 2, Padding.VALID),
        new Flatten(),
        new Dense(128), new ReLU(),
        new Dropout(0.25f),
        new Dense(10))) {

    net.fit(trainX, trainY, epochs, batch, testX, testY, true);
}
  • Adam(0.001) - the standard starting rate for CNNs; larger rates oscillate on image data.
  • Dropout(0.25) is active only during training (setTraining(false) is handled inside predict()).
  • Epochs/batch via args - defaults are epochs=8, batch=128; pass "-Dexec.args=DIR EPOCHS BATCH" or named flags --datadir --epochs --batch. One epoch takes ~18 s on CPU, so the full run finishes in about two minutes.

Evaluation

Metrics.printReport prints accuracy plus per-class precision/recall/F1 using FASHION_CLASS_NAMES, and the main method additionally prints ten textual sample predictions. Expected result after 8 epochs (~exact numbers vary slightly):

Accuracy:        0.917
class         precision    recall        f1
T-shirt/top      0.89        0.90       0.89
Trouser          0.99        0.98       0.98
...
Shirt            0.79        0.75       0.77   <- hardest class

Fashion vs digits: digit MNIST passes 99% with this same budget because digit shapes are stroke-based and consistent. Clothing categories differ mainly by texture and silhouette details - shirts, coats, pullovers and T-shirts all share the same outline, and their confusion cells dominate the error matrix. That makes Fashion-MNIST a much better proxy for real vision tasks.

How to Run

C:\Users\dell\Desktop\tfcapi-docs\projects\fashion-mnist-cnn> run.cmd
rem or with custom settings:
run.cmd C:\Users\dell\Desktop\data\fashion 8 128

Requirements: Maven on PATH, the four .gz files in the data directory, and the TensorFlow native DLLs at libtensorflow-cpu-windows-x86_64\lib (run.cmd points TF_CAPI_NATIVE_DIR there automatically).

Exercises

  2. Add a second pool + depthwise stage (14→7 spatial) and compare.
  3. Train only 1 epoch (run.cmd . 1) - already ~87%? Compare with the MLP-only baseline you would get from Flatten + Dense layers.
