Tutorial 16 - Toy Machine Translation

Project Overview

The flagship NLP demo of the library: translate sentences from an English-like language into an invented second language ("Kavish"). Real machine translation needs attention and huge corpora, but its core skill - lexical substitution plus word-order transformation - is fully learnable here. Kavish uses a completely different lexicon AND reads back-to-front:

EN : mouse slowly sees wolf
KV : nusu veni loma velu          (object, verb, adverb, subject)

Parallel Corpus

1,600 seeded sentence pairs over a 20-symbol vocabulary shared by both languages (8 nouns used as subjects/objects, 6 verbs, 6 adverbs):

Slot orderExample
English-likeSUBJ → ADV → VERB → OBJmouse slowly sees wolf
KavishOBJ → VERB → ADV → SUBJnusu(=wolf) veni(=sees) loma(=slowly) velu(=mouse)

Every source word has exactly one Kavish counterpart, so translation = dictionary lookup + full reordering. Split 1,280 train / 320 test via Datasets.trainTestSplit(n, 0.2, 7L); unseen test pairs are novel word combinations, not memorized sentences.

The Model

try (Regressor net = new Regressor(Optimizer.adam(0.01f), 42L,
        new Input3D(T, V),          // T=4 one-hot source words, V=20 symbols
        new LSTM(64),               // encoder: reads the English sentence
        new Dense(T * V))) {        // decoder head: 4 Kavish words at once

    net.setShuffleSeed(42L);
    EarlyStopping es = EarlyStopping.valLoss(15, true);
    net.fit(trainX, trainY, epochs, 32, testX, testY, true, es);
}
  • Targets are flattened float one-hot planes of the Kavish sentence - that's why training goes through Regressor, not a classifier.
  • Decoding = argmax per block of V outputs, then mapping ids to Kavish words for display.
  • Both languages share one id space here (nouns 0..7, adverbs 8..13, verbs 14..19) which keeps the plumbing simple.

Evaluation

Early stopping at epoch 32 - best val_loss 0.00001 at epoch 17
ran 32/150 epochs - best val MSE 0.000011 at epoch 17
word accuracy      : 1.0000
exact translations : 1.0000 (320/320)

Perfect held-out accuracy with early stopping at epoch 32: the task decomposes into lookup + reversal, exactly what this architecture absorbs easily (compare Tutorial 15, where sorting's global comparisons were far harder than reversing).

Exercises

  1. Add adjectives to both languages (extra slot in English, post-noun particle in Kavish) - at what corpus size does exact accuracy drop below 99%?
  2. Make 10% of pairs use a different order rule (S-V-O instead of O-V-S) without marking which - can one model serve both?
  3. Increase the noun pool to 30 words - how does V=30 change convergence epochs?
  4. Translate INTO English instead (swap src/tgt arrays) - identical difficulty? Should be; verify.
  5. Remove the LSTM and feed the same data to a pure Dense network - measure how much harder reordering becomes without recurrence.
