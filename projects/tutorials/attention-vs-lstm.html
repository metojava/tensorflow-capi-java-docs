Tutorial 17 - Attention vs LSTM

Project Overview

The first project built on the library's new SelfAttention layer answers the obvious question: when is attention actually better than an LSTM? The task chosen is needle-in-haystack retrieval - position 0 holds a PROBE digit and the model must decide whether that digit appears among the following payload digits. The answer requires comparing one position against every other, which is precisely what attention computes in a single hop while an LSTM has to accumulate membership evidence in its hidden state.

Dataset

6,400 seeded samples over a 40-symbol alphabet. Each sample is a length-16 sequence of one-hot planes (T=16, V=40): slot 0 carries the probe, slots 1..15 are distinct random digits that either include the probe (label 1, ~50%) or avoid it (label 0). Split 5,120 / 1,280 with Datasets.trainTestSplit(n, 0.2, 7L).

Two Architectures, Identical Budgets

// A: mini-transformer - pairwise matching, no recurrence
new Input3D(T, V),
new SelfAttention(),
new SelfAttention(),
new Flatten(),
new Dropout(0.2f),
new Dense(24), new ReLU(),
new Dense(2)

// B: recurrent baseline
new Input3D(T, V),
new LSTM(32),
new Flatten(),
new Dropout(0.2f),
new Dense(24), new ReLU(),
new Dense(2)

Both train with Adam(0.02) + weight decay 1e-4, identical seeds, batch 32 and EarlyStopping.valLoss(30, true). Note the deliberate design choice: no positional encoding exists yet, so the task is order-independent by construction.

Evaluation

=== A: SelfAttention x2 (mini-transformer) ===
ran 52/300 epochs - best val loss 0.0013
Accuracy: 1.0000

=== B: LSTM(32) ===
ran 135/300 epochs - best val loss 0.0001
Accuracy: 1.0000

Test accuracy: attention 1.0000 | lstm 1.0000

Both architectures eventually solve the task perfectly - the honest differentiator is convergence speed: attention needed 2.6× fewer epochs (early stop at 52 vs 135). That matches theory: probe-to-payload matching is one attention hop but a many-step recurrence chain.

What We Learned Building It

  • Attention needs a task where PAIRWISE relations carry the signal. Our first attempt (detect duplicates anywhere in a sequence) stalled both models at chance until the dataset grew 4x - equality kernels are hard to bootstrap from scratch at this scale without LayerNorm and learning-rate warmup (see the roadmap).
  • Retrieval tasks are the sweet spot: content-based matching IS the objective, so attention converges almost immediately once projections align.
  • Weight decay + dropout mattered: both models initially memorized the 5,120 training samples before regularization tamed validation loss.

Exercises

  1. Increase payload length to 31 (T=32) - does the LSTM's convergence gap widen faster than attention's?
  2. Remove one of the two SelfAttention blocks - how much harder is single-hop-only matching?
  3. Raise weight decay to 1e-3 - does the smaller effective capacity help or hurt generalization here?
  4. Add a second probe digit (both must be present for label 1) - attention should handle conjunctions more gracefully than the LSTM. Verify.
  5. Implement sinusoidal positional encodings as input features and re-run - can attention now ALSO solve position-dependent variants like "does position 3 hold the probe"?
