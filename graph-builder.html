GraphBuilder - Custom Graph Assembly

GraphBuilder is the public class that Sequential and Regressor use internally to assemble their TensorFlow graphs. It is public so you can build your own ops and losses on the same foundation - adding a new layer type or a custom objective requires no native changes, only graph wiring in Java.

1. Responsibilities

  • Op accumulation: every helper creates a TF op in the underlying NativeGraph and returns its handle (long) for wiring into further ops.
  • Parameter registry: trainable tensors created through the builder are tracked; models fetch them with paramOps()/paramTensors()/paramShapes().
  • Unique naming: unique(base) appends a counter, preventing name collisions between layers.
  • Seeded initialization: pass a seed to make all random initializations (Glorot weights) reproducible.

2. API Overview

Method Purpose
GraphBuilder(graph[, seed]) Wraps a NativeGraph; the seed controls weight-init randomness.
placeholder(name, dtype, shape) Input feed op (e.g. the model's x/y).
glorotParam(name, shape, fanIn, fanOut) Trainable parameter initialized Glorot-uniform: limit = sqrt(6 / (fanIn + fanOut)).
zerosParam(name, shape) Trainable parameter initialized to zeros (biases, BatchNorm beta).
onesParam(name, shape) Trainable parameter initialized to ones (BatchNorm gamma).
unary(type, name, in) / binary(type, name, a, b) Shorthands for elementwise TF kernels ("Relu", "Add", "Mul", "Sub", ...) with float dtype preconfigured.
constF32(name, v) / constI32Vec(name, vals...) / constInt32Tensor(name, values, shape) Constants for scalars, index vectors, shape tensors.
unique(base) Collision-free op name base_<n>.
graph() The underlying NativeGraph for building arbitrary ops fluently (op builder pattern: op(type, name).attr(...).input(...).build()).
paramCount() Parameters registered so far - used for per-layer attribution when freezing.
paramOps() / paramTensors() / paramShapes() Snapshot of all registered parameters as parallel arrays (feed handles, native tensors, shapes).

3. How Models Use It Internally

A condensed sketch of what Regressor's constructor does with the builder:

NativeGraph graph = new NativeGraph();
GraphBuilder gb = new GraphBuilder(graph, seed);      // seeded init

// input placeholder [-1, features]
long xPh = gb.placeholder("x", NativeTF.DT_FLOAT, Shape.of(-1, 4));

// one Dense(24) + ReLU stage, wired by hand:
long w      = gb.glorotParam("dense_w", new long[]{4, 24}, 4, 24);
long b      = gb.zerosParam("dense_b", new long[]{24});
long z1     = gb.binary("MatMul", "z1", xPh, w);
long z1b    = gb.binary("Add", "z1_bias", z1, b);
long hidden = gb.unary("Relu", "a1", z1b);

// targets + MSE loss
long yPh   = gb.placeholder("y", NativeTF.DT_FLOAT, Shape.of(-1, 1));
long pred  = ...;                                     // more layers...
long diff  = gb.binary("Sub", "loss_diff", pred, yPh);
long sq    = gb.binary("Mul", "loss_sq", diff, diff);

// gradients for every registered parameter in one call
long[] grads = graph.addGradients(lossOp, 0, gb.paramOps());

The point: parameters are ordinary placeholder-fed native tensors. The optimizer updates them in-place after each gradient step - nothing is copied into Java during training.

4. A Complete Standalone Example (Verified)

The smallest useful custom graph - linear regression y = w·x + b built, trained and queried by hand. This exact class compiles and runs against the 1.4.0 jar; it converges to y = 3.005x - 2.010 from noisy data generated with y = 3x - 2 + N(0, 0.3).

Placement requirement: low-level tensor allocation and reading (NativeTF.allocTensorF32 / tensorDataF32 / deleteTensor) are deliberately package-private, so the class must live in package com.example.tfcapi (drop it into your source tree under that package - the same thing the library's own SelfTest does).

package com.example.tfcapi;

import java.util.Arrays;
import java.util.Random;

public final class GraphLinearRegressionDemo {

    public static void main(String[] args) {
        // ---------- data: noisy line y = 3x - 2 -----------------------
        Random rnd = new Random(42L);
        int n = 100;
        float[] X = new float[n];
        float[] Y = new float[n];
        for (int i = 0; i < n; i++) {
            X[i] = i / 20f - 2.5f;
            Y[i] = 3f * X[i] - 2f + (float) rnd.nextGaussian() * 0.3f;
        }

        // ---------- graph: pred = x.w + b, loss = mean((pred-y)^2) ----
        try (NativeGraph g = new NativeGraph()) {
            GraphBuilder gb = new GraphBuilder(g, 42L); // seeded init

            long xPh = gb.placeholder("x", NativeTF.DT_FLOAT,
                    Shape.of(-1, 1));
            long yPh = gb.placeholder("y", NativeTF.DT_FLOAT,
                    Shape.of(-1, 1));
            long w = gb.glorotParam("w", new long[]{1, 1}, 1, 1);
            long b = gb.zerosParam("b", new long[]{1});
            long pred = gb.binary("Add", "pred",
                    gb.binary("MatMul", "mm", xPh, w), b);

            long diff = gb.binary("Sub", "diff", pred, yPh);
            long sq = gb.binary("Mul", "sq", diff, diff);
            long loss = gb.graph.op("Mean", gb.unique("loss"))
                    .attrType("T", NativeTF.DT_FLOAT)
                    .attrType("Tidx", NativeTF.DT_INT32)
                    .input(sq)
                    // GOTCHA: the axes constant must CARRY the value 0
                    // (values {0}, empty shape). An EMPTY int tensor
                    // reduces nothing - gradients then explode.
                    .input(gb.constInt32Tensor("axes",
                            new int[]{0}, new long[]{}))
                    .build();

            // ---------- d(loss)/d(w,b) for every parameter -------------
            long[] params = gb.paramOps();                 // [w, b]
            long[] gradPairs = g.addGradients(loss, 0, params);
            long[] fetchOps = new long[1 + params.length]; // loss, dW, dB
            int[] fetchIdx = new int[fetchOps.length];
            fetchOps[0] = loss;
            for (int i = 0; i < params.length; i++) {
                fetchOps[1 + i] = gradPairs[2 * i];
                fetchIdx[1 + i] = (int) gradPairs[2 * i + 1];
            }

            // ---------- hand-rolled training loop ----------------------
            try (Optimizer opt = Optimizer.sgd(0.02f);
                 NativeSession sess = g.newSession()) {
                opt.init(gb.paramShapes());

                // training feeds x, y and both parameters; Sgd updates the
                // parameter tensors IN PLACE, so handles stay valid.
                long[] trainFeeds = new long[2 + params.length];
                int[] feedIdx = new int[trainFeeds.length];
                long[] trainTs = new long[trainFeeds.length];
                trainFeeds[0] = xPh;
                trainFeeds[1] = yPh;
                System.arraycopy(params, 0, trainFeeds, 2, params.length);
                System.arraycopy(gb.paramTensors(), 0, trainTs, 2,
                        params.length);

                for (int step = 1; step <= 800; step++) {
                    long xT = NativeTF.allocTensorF32(new long[]{n, 1}, X);
                    long yT = NativeTF.allocTensorF32(new long[]{n, 1}, Y);
                    trainTs[0] = xT;
                    trainTs[1] = yT;

                    long[] got = sess.run(trainFeeds, feedIdx, trainTs,
                            fetchOps, fetchIdx);
                    float mse = NativeTF.tensorDataF32(got[0])[0];
                    if (step == 1 || step % 200 == 0) {
                        System.out.printf("step %3d  mse %.5f%n", step, mse);
                    }
                    opt.apply(gb.paramTensors(),
                            Arrays.copyOfRange(got, 1, got.length));
                    for (long t : got) NativeTF.deleteTensor(t);
                    NativeTF.deleteTensor(xT);
                    NativeTF.deleteTensor(yT);
                }

                float wv = NativeTF.tensorDataF32(gb.paramTensors()[0])[0];
                float bv = NativeTF.tensorDataF32(gb.paramTensors()[1])[0];
                System.out.printf(
                        "learned y = %.3fx + %.3f   (true 3.000x - 2.000)%n",
                        wv, bv);

                // ---------- inference: fetch pred (y never fed here) ---
                float[] probe = {-3f, 0f, 4f};
                long[] probeFeeds = new long[1 + params.length];
                int[] probeIdx = new int[probeFeeds.length];
                long[] probeTs = new long[probeFeeds.length];
                probeFeeds[0] = xPh;
                System.arraycopy(params, 0, probeFeeds, 1, params.length);
                System.arraycopy(gb.paramTensors(), 0, probeTs, 1,
                        params.length);
                long pT = NativeTF.allocTensorF32(
                        new long[]{probe.length, 1}, probe);
                probeTs[0] = pT;

                long[] out = sess.run(probeFeeds, probeIdx, probeTs,
                        new long[]{pred}, new int[]{0});
                float[] pv = NativeTF.tensorDataF32(out[0]);
                for (int i = 0; i < probe.length; i++) {
                    System.out.printf(
                            "x=%+.0f -> predicted %+.3f (true %+.1f)%n",
                            probe[i], pv[i], 3 * probe[i] - 2);
                }
                NativeTF.deleteTensor(pT);
                NativeTF.deleteTensor(out[0]);
            }
        }
    }

    private GraphLinearRegressionDemo() {}
}

Three lessons baked into this example:

  • Reduction axes gotcha: a reduction op's axes constant must carry the axis VALUE (values {0}, empty shape). Passing an empty int tensor silently disables the reduction - gradients then blow up ~n×.
  • In-place parameters: SGD mutates the registered tensors directly, so feed arrays keep working without refresh; fetched loss/gradient tensors must be deleted each step.
  • Feed only what a fetch needs: inference fetches pred, so the probe run feeds just x plus parameters - never feed stale tensor handles.

In practice you rarely re-derive this loop - Sequential/Regressor already implement it - but the same three ingredients (placeholders → ops → addGradients) extend to any architecture or loss the built-in models cannot express.

5. When to Reach for GraphBuilder

  • You need a custom loss not covered by cross-entropy/MSE (Huber, quantile, contrastive...).
  • You need an op combination that no layer provides (e.g. a specific attention variant).
  • You are prototyping numerics without wanting to touch the library itself.
  • Otherwise: prefer composing existing layers - it is less code and gets checkpointing for free.

6. Summary

  • GraphBuilder = op factory + parameter registry + unique namer over one NativeGraph
  • Seeded constructor makes init reproducible
  • glorot/zeros/ones param helpers cover layer weight conventions
  • graph.addGradients(loss, 0, paramOps) wires any differentiable graph into training
