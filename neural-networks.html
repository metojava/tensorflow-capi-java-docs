Neural Networks with TensorFlow C API Java

This page covers building neural networks using the tensorflow-capi-java library, from simple feedforward networks to CNNs and RNNs.

1. Network Architecture Types

1.1. Feedforward Neural Networks (MLP)

Multi-Layer Perceptrons (MLPs) are the simplest type of neural network, with fully connected layers where each neuron connects to all neurons in the previous and subsequent layers.

// Simple MLP for tabular data
try (Sequential net = new Sequential(new Adam(0.001f),
        new Input(784),           // 784 input features (e.g., flattened 28x28 image)
        new Dense(128), new ReLU(),
        new Dense(64), new ReLU(),
        new Dense(10), new Softmax())) {
    // Train on features and labels...
}

1.2. Convolutional Neural Networks (CNN)

CNNs are specialized for grid-like data (images, time-series) using convolutional layers that preserve spatial hierarchies.

// CNN for image classification (Fashion-MNIST / MNIST example)
try (Sequential net = new Sequential(new Adam(0.001f),
        new Input4D(28, 28, 1),   // 28x28 grayscale image
        new Conv2D(16, 3, 3, 1, 1, Padding.SAME), new ReLU(),
        new MaxPool2D(2, 2, 2, 2, Padding.VALID),
        new Conv2D(32, 3, 3, 1, 1, Padding.SAME), new ReLU(),
        new MaxPool2D(2, 2, 2, 2, Padding.VALID),
        new Flatten(),            // Flatten 3D feature maps to 1D vector
        new Dense(128), new ReLU(),
        new Dropout(0.25f),       // Regularization
        new Dense(10), new Softmax())) {
    // Train on image data...
}

1.4. Long Short-Term Memory (LSTM)

LSTMs are a special kind of RNN built around an explicit long-term memory: a cell state that runs through the whole sequence carrying important information for many steps - hundreds of tokens if needed - while gates forget whatever stops mattering. A plain RNN overwrites its entire memory every step and forgets almost immediately; an LSTM decides, per step, what to keep for the long run, what to write in, and what to reveal right now:

  • Forget gate - erases memory that is no longer relevant ("the previous sentence's filler words").
  • Input gate - writes new important information into long-term memory ("the subject mentioned 20 steps ago").
  • Output gate - exposes only what is useful for the current prediction.

This is what "capable of learning long-term dependencies" means in practice: because memory is carried additively instead of being rewritten, gradients survive across long spans and the network can connect, say, a forecasting signal from weeks ago to today's value. Full gate equations and usage: NLP → The Recurrent Family.

try (Sequential net = new Sequential(new Adam(0.001f),
        new Input1D(100),
        new LSTM(128),            // 128 LSTM memory cells
        new Dense(10), new Softmax())) {

1.6. Which Architecture for Which Project?

The type of input data decides the architecture - match the network to your data's shape:

Architecture Use when your data is... Typical tasks Showcase project
MLP
(Input + Dense)		 A fixed row of numbers per example (tabular/spreadsheet data) Price prediction, risk scoring, medical measurements, churn & fraud flags house-price-regressor, wine-quality, churn-prediction, fraud-detection
CNN
(Conv2D + Pool)		 A grid where nearby positions are related: images, spectrograms, sensor matrices Image classification, visual defect detection, denoising/autoencoding mnist-digit-cnn, fashion-mnist-cnn, autoencoder-small-images
RNN Sequences where only recent context matters and simplicity wins Short-pattern sequence tagging, teaching/demos of recurrence (superseded by LSTM/GRU for real work)
LSTM Sequences with long-range dependencies: time series, sentences, logs Forecasting, sentiment analysis, anomaly-in-time detection airline-lstm, sentiment-analyzer
GRU Same as LSTM, but you want fewer parameters and faster training on modest data Same tasks as LSTM; try GRU first on small datasets, LSTM if quality lags drop-in alternative in airline-lstm
  • Numbers in columns? Start with an MLP - it is the baseline every other architecture must beat.
  • Pixels or grids? CNN - weight sharing exploits spatial structure that Dense layers ignore.
  • Order matters (time, words)? Recurrent nets - LSTM/GRU carry memory across steps.
  • Combine freely: an Embedding + LSTM + Dense stack handles text; Conv2D features feeding Dense heads handle vision.

3. Building a CNN Step-by-Step

3.1. Input Layer

// For 28x28 grayscale images (Fashion-MNIST / MNIST)
new Input4D(28, 28, 1)

The Input4D layer declares that each sample is a 28×28 image with 1 channel (grayscale). The dimensions are (height, width, channels) in NHWC format.

3.2. Convolutional Layers

// First conv layer: 16 filters, 3x3 kernel, stride 1, SAME padding
new Conv2D(16, 3, 3, 1, 1, Padding.SAME)

Parameters:

  • filters: Number of output channels (feature maps)
  • kernelH, kernelW: Height and width of the convolution kernel
  • strideH, strideW: Vertical and horizontal stride
  • padding: SAME (output size = input size) or VALID (no padding)

3.3. Pooling Layers

// Max pooling: 2x2 pool, stride 2, VALID padding
new MaxPool2D(2, 2, 2, 2, Padding.VALID)

Reduces spatial dimensions by the pool size, assuming no overlap (stride = pool size).

3.3. Transition to Dense Layers

// After convolutional layers, flatten the feature maps
new Flatten()

Flattens the 3D output (height × width × channels) into a 1D vector for the fully-connected layers.

3.4. Regularization

// Dropout: randomly zero out 25% of activations during training
new Dropout(0.25f)

During training, each neuron has a 25% chance of being zeroed out, which prevents co-adaptation of features.

3.5. Output Layer


// Multi-class classification with 10 classes
new Dense(10), new Softmax()

The Dense(10) layer produces 10 logits (one per class), and Softmax converts them to probabilities summing to 1.

4. RNN/LSTM/GRU Details

4.1. Input Format


// For sequences of length 100 with 1 feature per time step
new Input1D(100);  // or new Input3D(100, 1, features) depending on layout

4.2. LSTM Internal Structure

LSTMs have three gates:

  • Forget gate: Decides what information to throw away from the cell state
  • Input gate: Decides which information to store in the cell state
  • Output gate: Decides what the hidden state should be

Each gate uses a sigmoid activation to output values between 0 and 1.

4.3. Training RNNs

  • RNNs are sensitive to vanishing/exploding gradients
  • Use Adam optimizer for faster convergence
  • Gradient clipping can help with exploding gradients
  • Teacher forcing (using ground-truth as input) during training

5. Network Initialization

All weights in tensorflow-capi-java use Glorot uniform (Xavier) initialization by default:

// Weights are initialized with uniform distribution
// Fan-in / fan-out based limit: limit = sqrt(6 / (fan_in + fan_out))
// This helps keep gradients in a reasonable range during backpropagation

5. Model Saving and Loading


// Save architecture + weights to disk
net.saveTo(Path.of("my_cnn.bin"));

// Load from checkpoint
Sequential loaded = Sequential.loadFrom(Path.of("my_cnn.bin"), optimizer);

// Or with custom learning rate
Sequential loaded = Sequential.loadFrom(Path.of("my_cnn.bin"), new Adam(0.001f));

Checkpoint format stores:

  • Architecture spec (layer types and parameters)
  • All trainable parameter values
  • Loss type and smoothing (v2 format)

6. Training with fit()


// Train for 10 epochs, batch size 128, with validation split
History history = net.fit(
    trainX, trainY,      // training data
    10,                  // epochs
    128,                 // batch size
    testX, testY,        // validation data (or null)
    true                 // verbose: print per-epoch summary
);

// History object contains:
history.trainLoss;     // per-epoch training loss
history.valLoss;       // per-epoch validation loss (if validation provided)
history.valAcc;        // per-epoch validation accuracy (if validation provided)

7. Summary

  • Start with Sequential + Input4D for image models
  • Stack Conv2D + ReLU + MaxPool2D blocks
  • Transition with Flatten → Dense layers
  • Use Dropout for regularization
  • Output with Dense(classes) + Softmax
  • Train with net.fit() using Adam(0.001)
  • Evaluate with Metrics.printReport()
  • Save/load with saveTo/loadFrom
